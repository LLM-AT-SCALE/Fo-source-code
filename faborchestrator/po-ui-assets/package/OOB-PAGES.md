# OOB PAGES - how Critical Manufacturing builds its own screens

Stock CMF pages, read from the live `CriticalManufacturing` tenant. Every one is
`IsSystem: True` and `IsTemplate: False` - these are the out-of-the-box screens the
platform ships, not customisations. No page in that tenant carries the template flag,
so "OOB template" means the stock pages themselves.

**Use these for STRUCTURE**: how a stock page lays out grids, wires a data source into a
grid, and arranges an action bar.

**Use the SAMPLES block for HOUSE STYLE.** Those are Athena's own delivered pages, and
Athena's conventions are what the artifact is judged against. Where a stock page and
Athena's page disagree on a convention - which keys to emit, how a converter is written,
whether a button carries its own caption - **Athena wins**.

These are page *definitions*: the JSON that lives inside the `Settings` attribute. The XML
envelope is written by our code, so it is not shown here.
