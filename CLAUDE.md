# FabOrchestrator

Everything lives in [`faborchestrator/`](faborchestrator): the app, its modules, the
per-module Docker build (`deploy/`) and the infrastructure templates still in use
(`deploy/cloudformation/`). Read [`faborchestrator/CLAUDE.md`](faborchestrator/CLAUDE.md)
before changing code and [`faborchestrator/DEPLOYMENT.md`](faborchestrator/DEPLOYMENT.md)
before deploying. [`README.md`](README.md) explains the product for people. This root holds only
repo-level tooling files.
